Telegram-аналитик для видеофайлов с использованием современных технологий обработки естественного языка, промпт-инжиниринга и искусственного интеллекта. Используйте пользователи для загрузки видео и получения детального анализа в автоматическом режиме. Бот обладает гибридным, многоуровневым функционалом, базовые команды работают напрямую через SQL-запросы, сложные процессы обрабатываются гигачат-LLM и выдают сложную аналитику на основе промптирования. Произведение охватывает весь временной период и все метрики согласно JSON-файлу, в том числе позволяет анализировать исходящую информацию за эти периоды, которые не соответствуют JSON.

Основной функционал:

Автоматический анализ видеофайлов через телеграм-интерфейс.

Генерация текстовых отчетов с помощью SQL-запросов и AI (GigaChatAI).

Извлечение ключевых кадров и метаданных.

Хранение исторических анализов в базе данных.

Интуитивное, разговорное и командное общение.

Программа имеет объемное тестовое покрытие, состоящее из Unit-тестов (модульных), интеграционных, полученных, тестов граничных случаев, тестов обработки ошибок, параметризованных тестов, тестов конфигураций, тестов безопасности/SQL-инъекций, тестов форм и парсинга, тестов логирования, тестов кэширования, тестов состояния (States test), покрывающих 89% всего функционала.

Запуск проекта: Подразумевается наличие у пользователя Docker, PostgreSQL в различных интерфесах, модели Gigachat2 lite.

Необходимая информация для клиентов: (src/.env) Проект уже настроен на работу с DB_HOST=localhost, DB_PORT=5432, DB_NAME=video_stats, для активации LLM в полях GIGACHAT_CLIENT_ID= и GIGACHAT_CLIENT_SECRET= введите свои данные.

Создание виртуального окружения

Установка всех зависимостей: pip install -r require.txt

Инициализация и создание таблиц в БД, в "человеческом формате ID" (JSON имеет только UUID-формат): db>python init_db.py

Запуск программы из точек входа: >cd src, >python app.py (логирование покажет подробную информацию о подключении всего функционала)

Запуск тестирования: базовая директория>python run_tests.py и в конце программы выдает результат в процентном соотношении в видеотаблице.

Проект доведен до результата Готовность к производству: система готова к эксплуатации: устойчива к страхам, защищена от некорректных входных данных и SQL-инъекций, подтверждена стандартным тестовым покрытием. Гибридная аналитика (SQL + AI): базовые отчёты усиливаются через жесткие SQL‑запросы к PostgreSQL; Сложная аналитика и интерпретация данных обрабатываются GigaChat AI с контролем промптов. Надёжность и отказоустойчивость: обработка ошибок API, таймаутов и пустых данных; при недоступности система LLM возвращает частичный результат на основе SQL‑данных (постепенная деградация). Безопасность: защита от SQL‑инъекций (параметризованные запросы), проверка форматов, контроль доступа по токенам, безопасное хранение секретов в .env. Контроль: качество тестовой пирамиды охватывает 89% функционала, включая модульные тесты, интеграцию, тесты безопасности, граничные случаи, обработку ошибок, логирование и кэширование.
